# ImageGen 提示词配方

使用 Codex 内置 ImageGen。每个不同场景分别生成，场景画面与手部素材保持独立。

## `reference-adapted` 场景静帧

调用 ImageGen 时附上项目 `style_reference`。用已确认的 `style_profile` 填写特征字段，不要求 ImageGen 识别或复现具体 IP、艺术家或来源身份。

```text
用途：科学教育白板动画
素材类型：原创白板绘制动画源静帧
主要请求：<该口播场景的一个具体视觉隐喻>
参考图用途：附图只用于高层级的<媒介、线条行为、配色角色、纹理、形状语言、阴影和绘制密度>
原创主体：<为本场重新设计的主体、轮廓、姿势、道具、关系和环境>
场景/背景：适配参考材质特征的浅色、近似均匀、可识别路径的白板或纸面
风格/媒介：<style_profile 摘要>；重要轮廓清晰；参考图支持时保留模拟媒介不规则性
构图/取景：精确 <16:9 或 9:16>；构图与参考图无关；所有主体完整可见；外边距至少 8%；全部画面内容位于高度 y=76% 以上
限制：只生成完整静帧；从 y=76% 到底部的全宽 24% 必须是完全空白且连续一致的背景，不得有主体、道具、地面线、箭头、标签、面板、装饰、阴影或纹理变化；不得出现手、手臂、马克笔、书写动作、伪文字、字幕、Logo、水印、签名或 UI；不得复现参考图中的可识别人物、脸、吉祥物、服装、品牌元素、标志性道具、精确姿势、机位或构图
避免：描摹；近似复制；换色；原构图换角色；一一对应的物体关系；微小细节；浅淡主轮廓；浑浊或强变化边缘
```

### 参考图适配规则

- 保留抽象工艺特征，不保留来源身份或场景内容。
- 改变主体身份、轮廓、姿势、道具、焦点布局、取景和对象关系。
- 所有场景共用一套 `style_profile`，不能每场重新猜测原始参考图。
- 使用 ImageGen 生成可见结构画面，精确符号使用程序添加。
- 若结果与参考图过于相似，必须更换视觉隐喻并重新构图，不能只做小幅修改。

## `editorial-character` 场景静帧

只根据场景调整主要请求、主体和构图，共享风格措辞保持不变。

```text
用途：科学教育
素材类型：白板手绘动画源静帧
主要请求：<该口播场景的一个具体视觉隐喻>
场景/背景：暖白色纤维白板或绘图纸，带轻微天然颗粒和极淡擦除痕迹
主体：<2–5 个大型可识别人物、物体、箭头或简单图示元素>
风格/媒介：编辑式白板马克笔插画；略带不规则的细黑线；少量低饱和橙色和薄荷色平涂；轻微手绘抖动；不使用纸张拼贴和照片写实
构图/取景：精确 <16:9 或 9:16>；构图位于 y=76% 以上；所有主体完整可见；外边距至少 8%；形状大而简洁，正常视频尺寸下清晰
光线/情绪：平面、明亮、友好的教育氛围；无方向性光照
限制：只生成完整静帧；从 y=76% 到底部的全宽 24% 必须是完全空白背景；不得出现手、手臂、马克笔、笔刷、书写动作、文字、字母、数字、字幕、Logo、水印、边框、阴影、渐变、额外纹理或 UI
避免：微小细节；低对比灰色轮廓；深色满背景；伪文字；无关对象重叠；不能解释口播的装饰涂鸦
```

### 一致性规则

- 所有场景保持相同背景色、线条粗细、配色角色和绘制密度。
- 用画面表达含义，不能把口播复制成画面文字。
- 每场只表达一个主要动作或关系。
- 箭头只用于解释流向、因果、变化或方向。
- 重要轮廓必须足够深以供阈值提取。
- 出现手或畸形文字时必须重新生成。

## 纯色抠像马克笔手

无论场景风格如何，默认复用自带手部。只有用户明确要求时才重新生成。提示词中的笔尖坐标必须与 `prepare-hand` 的锚点输入一致。

```text
用途：背景提取
素材类型：白板绘制动画可复用前景叠加层
主要请求：一只写实成年人的右手，以自然书写握姿持一支无品牌黑色毡尖笔；笔尖准确接触归一化画布 x=28%、y=5%；笔尖位于手部上方，手腕与前臂向下延伸并从底边退出；完整显示手、笔、手腕和一小段前臂
场景/背景：完全平坦的纯 #00ff00 抠像背景
风格/媒介：干净写实摄影棚抠图，手指结构自然，轮廓清晰
构图/取景：近似方形画布；笔尖是左上方最明确的功能点；方向清楚地由下向上；前臂只从底边退出；两侧留出充足空间
光线/情绪：主体上均匀柔和的中性棚拍光
限制：只能有一只手和一支笔；不得有绘画、白板、墨线、投影、接触阴影、反射、文字、Logo 或水印；背景必须是均匀 #00ff00，不能有渐变、纹理、地面或光照变化；主体内部不能出现绿色
避免：前臂从左、右或上方进入；横向手臂；笔尖靠近底部；多余手指；重复笔；手腕裁切；笔尖被遮挡；笔身弯曲；首饰；美甲；袖口 Logo
```

## 图像检查门

渲染前确认：

- 场景边缘和背景近似均匀。
- 重要线条为黑色或深炭色，不能是浅灰。
- 主体位于安全构图区，且没有意外文字或手。
- 所有画面痕迹结束于 y=76% 以上，下方全宽 24% 与空白背景一致。
- 参考图适配场景符合抽象风格特征，同时不复用可识别内容或布局。
- 手部抠像背景平坦、笔尖可见，记录锚点准确落在实体笔尖。
- 场景和手部素材均无水印或 Logo。
