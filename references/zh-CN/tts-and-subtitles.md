# TTS 与内嵌字幕

本 reference 同时覆盖默认的在线 Edge TTS，以及用户指定的 IndexTTS 等本地音色克隆管线。

## 默认规则

- 选声前先确定说话者性别。第一人称匹配说话主角；第三人称没有独立旁白时匹配主角；明确存在独立旁白时匹配旁白。
- 合成前在 `storyboard.json` 中把 `narrator_gender` 记录为 `male` 或 `female`。
- 使用 Edge 路径时，未指定中文男声使用 `zh-CN-YunxiNeural`，未指定中文女声使用 `zh-CN-XiaoxiaoNeural`；用户提供的 `--voice` 优先。
- 多主角或性别不明确且没有独立旁白时必须询问，不能根据次要角色猜测。
- 未特别要求时使用 `rate=+0%`、`volume=+0%`、`pitch=+0Hz`。
- Edge TTS 是在线依赖。若用户指定 IndexTTS 或其他本地音色克隆管线，必须使用该管线和最终音频，不能静默回退到 Edge TTS。必须逐字保留口播。
- 每个语义场景生成一个音频文件，不能按任意字幕行切分合成。

## 权威时间轴

默认 Edge 路径在语义场景切分完成后、渲染前运行 `edge_tts_pipeline.py synthesize`。脚本请求 WordBoundary 元数据，解码每场音频获取真实时长，向上对齐到下一视频帧，并把时长写回 `storyboard.json`。使用本地管线时，要在渲染前完成等价的合成、解码测时和时间轴写入。

合并音频时，每场补齐到与渲染器一致的帧对齐时长。字幕按可读中文短语分组，同时保留源时间戳：Edge 使用 WordBoundary；本地管线只有分段时间戳时，按语义标点切分，并依据口播字符比例确定内部 cue 时间，同时在最终报告中标注这一限制。这套共享场景时钟是唯一权威时间依据。

不得用渲染器估算的 `output/narration.srt` 覆盖定时字幕。权威文件为最终 TTS 音频及其匹配的时间戳 SRT，通常为 `audio/narration.m4a` 和 `audio/narration.srt`；实际路径和时间基准必须记录在 `tts` 中。

## 字幕样式

- 字幕在画面下方全宽 24% 安全区内居中，使用一行或两行。
- 每条优先 8–22 个中文字符，长分句尽量按语义拆分。
- 使用白字、紧凑深色描边和透明背景；除非用户明确要求，不添加黑色或半透明字幕框。
- 1920×1080 画面可从约 48 px 字号和 59 px 底边距开始。
- 场景主体、关键内容和活动笔尖必须避开字幕区，不能靠移动字幕绕开构图问题。

## 故障处理

- 缺少 `edge-tts` 时，创建项目本地虚拟环境，并只安装 `check_env.py` 报告的依赖。
- 在线合成失败时重试一次；再次失败则报告网络或服务故障，不能伪造时间戳。
- 选定声音不可用时，运行 `edge-tts --list-voices`，选择性别和语气最接近的可用固定 `zh-CN` 声音。
- FFmpeg 缺少 `subtitles` 过滤器时，使用带 libass 的 FFmpeg；否则交付独立定时 SRT，并明确字幕未烧录。
- 如果本地时间轴只有一条很长的分段 cue，不能在按比例切分后声称是逐词对齐；必须保留分段边界，并标注为短语级或比例时间轴。

## 验收

- 最终 MP4 包含一条 H.264 视频流和一条 AAC 音频流。
- 第一个词、每个场景边界和最后一个词均与绘制时间轴对齐。
- 用户提供的每个分句按顺序出现一次。
- 字幕在正常播放尺寸下清晰，并始终位于下方安全区。
- 最终时长与帧对齐 TTS 时间轴误差不超过一帧。
- `tts.narrator_gender` 匹配说话主角或旁白；除非用户明确指定例外，声音报告性别也必须一致。
- `tts.engine`、非敏感的音色参考标识、最终音频路径、字幕路径和时间基准均已记录，并且与实际交付文件一致。
